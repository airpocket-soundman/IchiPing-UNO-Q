# 発音不良の検証まとめ・別環境での実験計画

更新: 2026-09-11 JST。**次環境はアンプ・マイク・オシロあり、ロジアナなし**。
最初にこの文書を読み、詳細は[信号監査記録](reports/2026-09-11-i2s-signal-audit.md)を参照する。

## 1. 現在地：まだノイズ対策は実装していない

今回変更したのは測定・解析コードと試験手順。**I²S開始停止処理、アンプSD配線、Device Tree、カーネルモジュールの対策変更は今回行っていない**。同じ接続・同じ制御なら発音不良の再発は想定される。「データ一致」は「ノイズ解消」ではない。

アンプ・マイクは元IchiPingで動作実績あり（ユーザー確認）。優先調査対象はUNO Q側の開始停止制御・電圧/GND・シールド経由の接続。UNO Q本体の故障、アンプ不良、単一原因はいずれも未確定。

## 3. 別環境で最初に行うこと

1. ボード識別、kernel/module、実行中アプリ、実際の配線・電源を確認。サーボは動かさない。
2. アンプを無効化できる手段を確保するまで、音声試験を自動再開しない。配線変更は電源OFFで実施。未給電アンプ/マイクに信号線だけ接続しない。
3. オシロの型番、チャンネル数、帯域、メモリ長、同時取得時サンプルレート、プローブ倍率、DC結合、補償・電圧校正を記録。
4. 以前のOWON API測定はレンジによる電圧不整合があった。別環境でも同じ機材/APIなら、既知電圧と補償信号で各使用レンジを確認してから電圧値を信用する。未解決なら公式アプリまたは検証済み測定手段を使う。
5. 2chオシロを基本とし、以下の組合せを同一条件で繰り返す。4信号同時取得やI²Sデコード機能は前提にしない。別々の試行の波形を単一イベントの同時測定として扱わない。

## 4. 対策を実装してから比較する

### SD制御（未実装・ピン未選定）

実物モジュールのSDプルアップ/プルダウンと電圧を確認し、空きGPIOとレベル適合を決める。GPIO番号や抵抗値を推測で指定しない。必要ならトランジスタ/オープンドレイン回路を介し、GPIOリセット・高インピーダンス時もアンプ無効になる構成にする。SDのバイアスはチャンネル選択にも関係するので、有効時の選択モードも記録する。

- 開始: アンプ無効を維持 → ゼロPCMでBCLK/WS/DATAを安定 → アンプ有効 → フェード付きサイン/後でchirp。
- 停止: ゼロPCM → アンプ無効 → クロック停止。
- 固定sleepだけで順序成立と見なさず、オシロで実際のSD・WSを確認する。
- 例外・PCM underrun・停止要求・再起動/電源断の扱いも設計する。500msリセット予約は音響保護の代わりにならない。

常時ゼロPCMでクロックを維持する方式は、頻繁な開始停止を減らす別案。ただしプロセス異常時のSD停止が別途必要。SD対策とストリーム方式を同時に変更せず、どの変更が改善したか分かる順に試す。

## 5. オシロを使う順序と判定

| 試験 | 外部ボード・オシロ接続 | 見るもの／次へ進む条件 |
|---|---|---|
| A1：無負荷クロック | アンプ・マイクなし。CH1=BCLK、CH2=WS | 対策後も約3.072 MHz/48 kHz。開始・停止を長時間窓、定常部を短時間窓で別取得 |
| A2：有効化順序 | アンプ未接続のSD制御点。CH1=SD、CH2=WS | 開始/停止ともSDの有効化がWSの安定区間内に収まる。エッジ順が曖昧なら停止 |
| A3：補助確認 | CH1=SD、CH2=BCLK | BCLKだけ動く区間でアンプ有効にならないこと。A2と同一条件で繰返す |
| B1：負荷時入力 | アンプのみ接続、SD無効、スピーカーなし。CH1=BCLK、CH2=WS。次にCH1=BCLK、CH2=DIN | アンプ端でHigh≥1.3 V、Low≤0.6 Vを測定誤差込みで確認。オーバーシュート/リンギング/共通GNDを確認 |
| B2：電源・SD | アンプ接続。CH1=SD、CH2=VIN、次にSD/WS | 電源投入・起動・停止で意図しない有効化や電源低下がない。SDの実電圧確認 |
| C1：ゼロPCM | 上記合格後、アンプ＋スピーカー、マイクなし | 開始/ゼロ送信中/停止のノイズを独立録音と聴取で区別。持続ノイズなら即中止 |
| C2：サインPCM | 同じ配線で微小サイン。独立録音器を固定位置に置く | 440 Hzが観測され、開始/停止ノイズと定常ノイズを分けて評価。以前の危険な停止方式を再現して比較する必要はない |
| D：マイク追加 | 電源OFFでマイク追加。再生のみ→再生＋録音を比較 | アンプ端BCLK/WSに変化がないか、ノイズが追加されるか。独立録音とINMP441録音を別々に評価 |

短時間窓では可能なら100 MS/s以上を実際の2ch設定で確認する。25 MHz級オシロでは周期や大きな波形崩れは見られても、10 nsセットアップ/ホールドや細かなジッタを完全保証できない。長時間窓の低サンプルレートでBCLK振幅/形状を判定しない。全PCM一致は今回のロジアナ測定の範囲だけで主張する。

**スピーカー出力はBTL。OUT+またはOUT−へ通常プローブのGNDクリップを接続しない。** 出力差動測定が必要なら適切な差動プローブ、または両GNDを回路GNDに接続した2ch差分を、各入力の定格/同相範囲/接地を確認して使う。USB絶縁がチャンネル間絶縁を意味するとは限らない。Class-DのPWM波形をそのまま音声波形と解釈しない。

## 6. 中止条件と記録

- SD順序不成立、予期しない連続音、異常発熱、電源不安定、ALSAカード未初期化、測定器の校正不良では進めない。
- 異常時はまず独立したアンプ無効化/電源遮断手段を使う。ソフト再起動の完了を待つ方式だけにしない。
- ALSAカードなしのまま音声を出そうとしない。ログを保存する。過去のADSP stop/startは無音状態での復旧実績であり、発音中の緊急停止手順ではない。
- 試験ごとに日時・Git commit・ボードserial・kernel/module hash・配線写真・接続ボード・SD回路・電源・オシロ設定・波形CSV/スクリーンショット・独立録音・期待値/実測値/判定を新しいフォルダへ保存。
- 「対策前＝今回の無負荷計測/既存発音記録」「対策後＝SD等の変更と測定」を明記。改善しなければSDだけを原因と断定せず、アンプ端信号/GND/電源を優先調査する。
- 成功は実際の発音で確認する。データ一致、ALSA正常終了、無負荷の全ゼロ録音だけでは完了にしない。
