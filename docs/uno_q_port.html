IchiPing UNO Q 移植方針・センサ接続・GPIO

対象: Arduino UNO Q（QRB2210 Linux + STM32U585 / Zephyr）

1. 開発方針

IchiPingの信号処理・32状態ラベル・学習資産とILI9341外部TFTを引き継ぎ、ボード依存層だけをUNO Qへ置き換える。リアルタイムI/OはSTM32U585、モデル推論・ログ・将来のネットワーク機能はDebian Linux側に置き、Arduino Router Bridgeで接続する。オンボードLED Matrixは使用しない。

  1. Phase 0 — bring-up: ILI9341、Bridge、GPIO、PCA9685検出を実機確認する。
  2. Phase 1 — actuator: PCA9685の校正値と5台のSG90制御を移植する。
  3. Phase 2 — acoustic: QRB2210 MI2S0を第一候補、USB Audioをフォールバックとして16 kHzモノラル録音・ping再生を確立する。
  4. Phase 3 — inference:既存モデルをbaselineとしてLinux側へ移し、精度優先の大型モデルとensembleを外部評価で比較する。
  5. Phase 4 — standalone:起動時実行、ログ、ネットワーク通知を統合する。

GPIO接続図を開く — スイッチ、雨センサ、PCA9685、外部5 V電源を一枚にまとめている。

旧IchiPingシールド互換: TFT制御線は元実装と同じA2/A3/A4/A5を使う。FRDM-MCXN947でD18/D19と呼ばれていたPCA9685のSDA/SCL端子は、同じUNOヘッダ物理位置にあるUNO QのD20/D21へそのまま接続される。
電圧: MCU GPIOは3.3 Vロジック。公式資料ではA0/A1以外は5 V tolerantだが、周辺機器は原則3.3 Vで統一する。PCA9685はVCC=3.3 V、サーボ電源V+=外部5 Vとし、UNO Q・PCA9685・サーボ電源のGNDを共通化する。シールドの安定化5 V入力はUNO Qの+5V端子へ接続する。VINは7-24 V入力なので5 Vを接続しない。受けた5 Vはサーボ電源用XH2へ直接分岐し、サーボをUNO Qの3V3から給電しない。

3. センサ・アクチュエータ接続

機器UNO Q接続移植判断
PCA9685VCC→3V3、GND→GND、SDA→D20、SCL→D21、V+→外部5 VPhase 0で0x40 ACKを検査。Phase 1で既存の5ch座標・校正を移植。
SG90 ×5PCA9685 ch 0–4既存のa/b/c/AB/BC順を維持。外部5 V電源を使用。
状態スイッチ ×5D3–D7とGNDの間既存の5-bitラベル順を維持。
EXECD8とGNDの間ILI9341のpingアニメーション後、Linux側へ推論要求。
降雨入力D9、GND、3V3入力が5 Vになるモジュールは分圧またはレベル変換を追加。
INMP441JMISC MI2S0（1.8 V）候補1.8 V動作可能。Device Tree・ALSA capture routeとWS／DATA割当を実機検証後に確定。
MAX98357AJMISC MI2S0（1.8 V）候補1.8 Vロジック入力に適合。Device Tree・ALSA playback route検証後に確定。
音響の第一候補: QRB2210のMI2S0をJMISCまたはUNO Breakout Carrierから取り出し、Debian ALSAでINMP441とMAX98357Aを扱う。raw JMISCはCLK=46、WS=48、DATA0=50、DATA1=52、すべて1.8 V。標準UNOヘッダには出ていない。Device Tree・codec DAI・ALSA routeを確定するまでは接続せず、成立しない場合は給電対応USB-Cハブ + Linux互換USB Audioへ切り替える。

4. ILI9341 TFTの表示規約

ILI9341 240×320を横向きで使用する。左から5個のタイルが窓a、窓b、窓c、扉AB、扉BC。緑は開、暗色は閉。右端は下から伸びる信頼度バー。ping／推論中は画面内へ縮む枠アニメーションを表示する。オンボードLED Matrixは使用しない。

5. Phase 0 合格条件

  • UNO QがUSBでCOM/ADBの両方として認識される。
  • App Labアプリがビルドされ、STM32スケッチとLinux Pythonが起動する。
  • Router Bridge経由で状態値と信頼度をILI9341に表示できる。
  • D3–D7、D8、D9を安全に読み取れる。
  • PCA9685接続時は0x40を検出し、未接続時もアプリが継続する。
