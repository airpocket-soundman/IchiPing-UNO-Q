Arduino UNO Q port / Phase 0 bring-up

IchiPing UNO Q

一発のpingを聴き、窓3枚と扉2枚の状態を推定するIchiPingを、Arduino UNO QのLinux + リアルタイムMCU構成へ移植する独立プロジェクトです。

元のIchiPingリポジトリには変更を加えません。

現在の到達点

UNO Q実機

USB COMとADBを認識し、QRB2210 DebianとSTM32U585 / Zephyrの両方を確認。

LED Matrix

内蔵8×13 Matrixで5状態、信頼度、pingアニメーションを表現。

GPIO / I²C

D3–D9の入力と、D20/D21上のPCA9685（0x40）検出を実装。

MCU–Linux

Arduino Router Bridgeで推論要求と結果表示を往復。現在の結果は明示的なloopback。

実機テスト

2026-08-21 Phase 0 software smoke test PASS。UNO Qへ23,680 bytesのスケッチを書き込み、Bridge往復、Matrix API、GPIO読取、PCA9685未接続時の継続動作を確認しました。サーボPWMは未出力です。

ALSAデバイスは列挙されますが、外部音響機器なしの16 kHzモノラル録音はEINVALで、音響経路は未合格です。
