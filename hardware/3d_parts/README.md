# UNO Ping model house — 3D-printed parts

STL files for the model house used in the UNO Ping experiments: three rooms in a row, three windows and two inner doors, with the speaker and microphone in room A (see [Hardware and wiring](../../docs/uno_q/hardware.md)).

| File | Part |
|---|---|
| `floor1.stl`, `floor2.stl`, `floor3.stl` | floor sections |
| `ceiling1.stl`, `ceiling2.stl` | ceiling sections |
| `pillar2.stl`, `pillar3.stl` | pillars |
| `wall 100.stl`, `wall 150.stl` | plain wall panels |
| `wall 100 window.stl` | wall panel with a window opening |
| `wall 100 speaker.stl` | wall panel with the speaker opening (room A) |
| `wall 150 door.stl` | wall panel with a door opening |
| `window.stl` | window, opened and closed by a servo |
| `door.stl` | inner door, opened and closed by a servo |
| `speaker holder.stl` | speaker holder (room A) |
| `mic holder.stl` | INMP441 microphone holder (room A) |

The servos, electronics and other purchased parts are listed in the bill of materials in [Hardware and wiring](../../docs/uno_q/hardware.md).
